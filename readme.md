This project takes the user on a little tour of my room
In the first page, the user is in my room with images of furniture taken from the internet.
Once the closet is clicked, the user moves to the other page.

In the second page, the user gets to scroll between different tops and pants to pick. These images are my own.
I used this website to aquire the slideshow:
https://www.w3schools.com/w3css/w3css_slideshow.asp
There is a text linking the user to the next page.

In the third page, my bag is displayed with what i usually carry in it.
There are short captions for whats relevant to the items.
